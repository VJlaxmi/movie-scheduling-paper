Instance parameters follow established ranges from the scheduling literature~\citep{bomsdorf2008,nordstrom2022}: actor wages \$80--\$1{,}000/day, scene durations 1--4 hours, 20\% precedence probability, 80\% actor availability, and 85\% location availability.
Transfer costs follow the three-tier hierarchy of Eq.~\eqref{eq:transfer_cost}: intra-town \$100--\$500, inter-town \$500--\$2{,}000, inter-city \$2{,}000--\$8{,}000.
Each instance includes time windows (40\% of scenes), soft deadlines with penalties (30\% of scenes), actor criticality weights ($\kappa^A \sim U(1,10)$), location criticality weights ($\kappa^L \sim U(1,10)$), and maximum consecutive working days ($\bar{h}_a \in \{3,4,5,6\}$).
All 13 constraint families (C1--C13) from Section~\ref{sec:formulation} are active across all instances.

\subsection{Algorithms Compared}

We compare eight algorithm configurations:

\begin{itemize}
    \item \textbf{BDM-AOS}: Full proposed algorithm (SIG decomposition, NSGA-II on block permutations with Q-learning AOS, greedy reassembly decoder enforcing all 13 constraint families; population~20, generations~40, $p_c{=}0.9$, $p_m{=}0.3$).
    \item \textbf{BDM-NoAOS}: Ablation with uniform random operator selection (no Q-learning).
    \item \textbf{BDM-NoSIG}: Ablation replacing Louvain community detection with random equal-sized blocks.
    \item \textbf{BDM-NoSpecOps}: Ablation disabling domain-specific operators (LAX crossover and ACM mutation), retaining only PMX, OX, swap, and block\_swap.
    \item \textbf{BDM-Flat}: Ablation using one scene per block (scene-level permutations through the BDM framework).
    \item \textbf{Standalone GA}: Standard genetic algorithm on scene permutations with greedy decoder enforcing all 13 constraint families (population~50, generations~100, OX crossover, swap mutation, $p_c{=}0.85$, $p_m{=}0.15$)~\citep{goncalves2011}.
    \item \textbf{Standalone PSO}: Discrete PSO following \citet{kennedy1995} with the same constraint-enforcing greedy decoder (swarm~30, iterations~100, $w{=}0.7$, $c_1{=}1.5$, $c_2{=}1.5$).
    \item \textbf{Full MILP}: Exact solver (CBC) with 60s time limit, implementing all 13 constraint families including town activation variables and geographic logistics constraints (\ref{c10}--\ref{c12}); computed only for $n \leq 15$ due to intractability~\citep{hart2011}.
\end{itemize}

Each metaheuristic configuration is run with \textbf{30 independent random seeds}.
MILP uses a single deterministic run.
All experiments are conducted on a standard desktop (Intel i7, 16GB RAM) using Python~3.14.

\paragraph{Key observations from Table~\ref{tab:results}:}
\begin{enumerate}
    \item \textbf{Small instances (S10--S15)}: All methods achieve comparable costs.
    BDM-AOS finds the global optimum on S10 (cost 12{,}503, zero variance) and a strong deterministic solution on S15 (15{,}487, zero variance).
    PSO is marginally better on S15 (15{,}257 vs.\ 15{,}487).

    \item \textbf{Medium instances (S20--S30)}: GA and PSO outperform BDM-AOS.
    On S20, BDM-AOS (40{,}346) costs 24\% more than PSO (32{,}548) because the SIG produces only $K{=}6$ blocks, yielding $720$ permutations---too few for NSGA-II to differentiate meaningfully, while GA/PSO explore the full $20!$ space.
    On S30, the gap is 33\% (BDM-AOS: 49{,}768 vs.\ GA: 37{,}436).

    \item \textbf{Transition at S50}: The gap narrows sharply.
    BDM-AOS (119{,}129) is only 5.6\% worse than PSO (112{,}774) despite operating on $K{=}14$ blocks ($14!{=}8.7 {\times} 10^{10}$ permutations) versus the full $50!$ space.
    BDM-AOS achieves noticeably \emph{lower variance} (std~4{,}527 vs.\ GA's 9{,}977), indicating more consistent performance.

    \item \textbf{Crossover at S75 ($K{=}17$)}: BDM-AOS \textbf{outperforms both baselines}.
    BDM-AOS (134{,}544) beats GA (169{,}625) by \textbf{20.7\%} and PSO (165{,}999) by \textbf{19.0\%}, while running in 1.10s versus GA's 6.16s (\textbf{5.6$\times$ faster}).

    \item \textbf{Dominance confirmed at S100 ($K{=}26$)}: BDM-AOS (232{,}767) beats GA (272{,}103) by \textbf{14.5\%} and PSO (265{,}545) by \textbf{12.3\%}, with a runtime speedup of $\mathbf{5.5\times}$ over GA (1.61s vs.\ 8.78s).
    The advantage narrows slightly from S75, consistent with the $K{=}26$ block space ($26! \approx 4.0 \times 10^{26}$) becoming large enough that BDM-AOS's fixed population of 20 cannot fully exploit it.
    This confirms the central hypothesis: decomposition-guided search becomes superior as problem size grows and the full permutation space becomes intractable.
\end{enumerate}

\subsection{Statistical Analysis}
\label{sec:stats}

We employ the Friedman test~\citep{garcia2009} across all instance sizes to assess overall algorithm ranking, followed by Holm's post-hoc correction~\citep{holm1979} for pairwise comparisons.

For each instance size, we compute pairwise Wilcoxon rank-sum tests (Mann-Whitney $U$) with Holm-corrected $p$-values at $\alpha{=}0.05$.
On S20--S30, PSO and GA significantly outperform all BDM variants ($p < 0.001$).
On S50, the difference between BDM-AOS and GA/PSO is not statistically significant at the 5\% level.
On S75, BDM-AOS significantly outperforms both GA ($p < 0.001$) and PSO ($p < 0.001$).
On S100, BDM-AOS again significantly outperforms both GA ($p < 0.001$) and PSO ($p < 0.001$).

\paragraph{Ablation findings:}
\begin{enumerate}
    \item \textbf{SIG decomposition is critical.}
    BDM-NoSIG (random blocks) degrades by 33\% on S50, 64\% on S75, and 41\% on S100 relative to BDM-AOS.
    Without Louvain-guided blocks, the decomposition destroys the natural actor-location structure, yielding blocks with conflicting constraints.

    \item \textbf{AOS provides modest improvement at medium scale.}
    BDM-NoAOS degrades by 1.7\% on S50 and 2.0\% on S75, but only 0.1\% on S100.
    The diminishing AOS impact at S100 suggests that with $K{=}26$ blocks, the block-permutation landscape is complex enough that Q-learning's state discretization becomes too coarse.

    \item \textbf{Domain-specific operators show scale-dependent impact.}
    BDM-NoSpecOps degrades by only 1.3\% on S50 but jumps to 30.4\% on S75, before dropping back to 0.2\% on S100.
    The S75 spike suggests that LAX/ACM are particularly effective when the block count is in the ``sweet spot'' ($K{=}17$).

    \item \textbf{BDM-Flat confirms the critical role of decomposition granularity.}
    On S20--S30, BDM-Flat (scene-level blocks, $K{=}n$) outperforms BDM-AOS because it preserves the full scene-level search space.
    On S50 ($K{=}50$), BDM-Flat degrades by 8.6\%; on S75 ($K{=}75$), by 59.9\%; on S100 ($K{=}100$), by 30.3\%.
    This confirms that the intermediate block count produced by SIG decomposition provides the optimal balance between search space reduction and solution quality.
\end{enumerate}

\subsection{Pareto Front Analysis}

BDM-AOS employs NSGA-II to jointly optimize cost and makespan.
However, the greedy decoder produces a fixed makespan for each instance regardless of block ordering (e.g., 40~days on S75), causing the Pareto front to collapse to a single non-dominated makespan value.
Cost varies across block permutations, but makespan does not, so the front is effectively one-dimensional.
This observation---that cost and makespan are not genuinely conflicting under greedy decoding---is itself a methodological finding.
Future work should explore alternative decoders (e.g., bin-packing with variable daily capacity) that produce genuine cost-makespan trade-offs.
